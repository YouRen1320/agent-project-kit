# Final Report Template

Use this after implementation, documentation, review, deployment, data work, or other completed delivery.

```md
Outcome:
- <WHAT_WAS_ACHIEVED>

Scope changed:
- <FILES_REPOSITORIES_COMPONENTS>

Key decisions:
- <DECISION_AND_RATIONALE>

Verification:
- Passed: <COMMANDS_TESTS_AND_EVIDENCE>
- Not verified: <ITEM_AND_REASON>

Repository status:
- <REPOSITORY>: <BRANCH_COMMIT_PUSH_PR_OR_MERGE_STATUS>

Deployment and data:
- Deployment: <STATUS_OR_NOT_APPLICABLE>
- Schema/data/config: <STATUS_OR_NOT_APPLICABLE>
- Rollback readiness: <STATUS_OR_NOT_APPLICABLE>

Compatibility compromises:
- <NONE_OR_EXPLICIT_COMPROMISE_WITH_REMOVAL_CRITERIA>

Intentional non-goals / not done:
- <ITEMS>

Remaining risks or follow-up:
- <RISK_OWNER_AND_NEXT_STEP>
```

Rules:

- Lead with the outcome.
- Separate verified evidence from inference.
- Do not claim deployment, publication, or tests that did not occur.
- Always state compatibility compromises and intentional non-goals, even when the value is `None`.
- Do not include secrets, credentials, personal data, or sensitive logs.
