# Review Report Template

Use with `../workflows/code-review.md`.

```md
Findings

- [<SEVERITY>] <FILE>:<LINE> — <ISSUE>. Impact: <IMPACT>. Recommendation: <RECOMMENDATION>.

Open questions

- <QUESTION_OR_NONE>

Residual risks / test gaps

- <RISK_OR_NONE>

Summary

- <BRIEF_SCOPE_AND_CONCLUSION>
```

If there are no findings, say so explicitly; do not omit residual risks or unverified areas.
